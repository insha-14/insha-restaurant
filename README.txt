INSHA RESTAURANT WEBSITE
========================

This project contains 6 HTML pages:
1. index.html       - Home
2. menu.html        - Menu
3. about.html       - About Us
4. gallery.html     - Gallery
5. reservation.html - Reservation form
6. contact.html     - Contact form

Also included:
- style.css  : shared design and responsive styling
- script.js  : mobile navigation and demo form messages

HOW TO OPEN
1. Extract the ZIP file.
2. Open the folder in VS Code.
3. Open index.html.
4. Right-click and choose "Open with Live Server" (if Live Server is installed),
   or double-click index.html to open it in a browser.

NOTES
- Food photos load from Unsplash, so an internet connection is required.
- Reservation and contact forms are front-end demos only. They do not save or
  send information. A backend (for example Node.js + Express + MySQL) is needed
  for real bookings and messages.
- Replace the sample address, phone number, email and menu prices with your own.
